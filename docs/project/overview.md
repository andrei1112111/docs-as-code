# Анализатор отзывов

Сервис автоматически определяет тональность отзыва: положительная, нейтральная
или отрицательная. Пользователь отправляет текст отзыва, а система показывает
результат классификации и уровень уверенности модели.

Основные пользователи:
- посетитель сайта (автор отзыва);
- модератор контента.

Основные функции:
- отправка текста отзыва;
- определение тональности отзыва;
- просмотр результата анализа;
- история проверeнных отзывов.

## Комплект документации

1. **Описание проекта** - для заказчика и новых участников команды,
   чтобы за несколько минут понять назначение сервиса и его пользователей.
2. **Требования** (User Stories и Use Case) — для команды разработки и тестирования,
   чтобы точно знать, что и для кого нужно реализовать и по каким критериям принимать.
3. **Архитектура системы** - для разработчиков,
   чтобы понять, из каких компонентов состоит сервис и как они взаимодействуют.
4. **Документация API** - для интеграторов и внешних разработчиков,
   чтобы подключить сервис анализатора к своим системам.
5. **Документация ML-модели** - для ML-инженеров,
   чтобы знать, как обучена и дообучена модель тональности и как еe оценивать.
6. **Руководство пользователя** - для модераторов и посетителей,
   чтобы научиться пользоваться сервисом без помощи разработчиков.
