# Model Card

## Общая информация

**Название модели:** `seara/rubert-tiny2-russian-sentiment`

**Источник:** [страница модели на Hugging Face](https://huggingface.co/seara/rubert-tiny2-russian-sentiment)

**Автор / организация:** seara (пользователь Hugging Face).

**Задача модели:** многоклассовая классификация тональности коротких текстов на русском языке. Классы: `neutral`, `positive`, `negative`.

**Язык:** русский.

**Лицензия:** MIT (указана в карточке модели).

**Базовая модель:** [cointegrated/rubert-tiny2](https://huggingface.co/cointegrated/rubert-tiny2) — компактный русскоязычный BERT-энкодер.

**Данные для обучения:** объединение пяти наборов данных — Kaggle Russian News, LinisCrowd 2015, LinisCrowd 2016, RuReviews и RuSentiment (по карточке модели).

## Использование в проекте

В сервисе "Анализатор отзывов" модель определяет тональность отзыва - это основная ИИ-функция проекта.

Модель используется в сценарии UC-01:

1. Посетитель вводит текст отзыва (10–2000 символов).
2. Система проверяет длину и корректность текста.
3. Backend отправляет текст в модель при обработке `POST /analysis`.
4. Модель возвращает вероятности трех классов.
5. Система берет класс с наибольшей вероятностью как `sentiment`, а его вероятность — как `confidence`.
6. Результат сохраняется в историю и отдается по `GET /analysis/{id}`.

По US-02 `confidence` показывается пользователю и используется для правила: при уверенности ниже 0.6 результат помечается как «требует проверки». Список моделей и их версий доступен через `GET /models`, версия модели указывается в поле `modelVersion` результата анализа.

Модель используется как готовая — в сервисе она не обучается и не дообучается. Ее задача ограничена классификацией тональности; решения о блокировке или удалении отзывов принимает человек.

Сценарий подробнее описан в [требованиях](../project/requirements.md), контракт сервиса — в [документации API](../api/index.md).

## Входные данные

- Один текст отзыва на русском языке длиной от 10 до 2000 символов.
- Текст может содержать эмодзи, сленг, опечатки и вкрапления других языков — такие случаи авторами модели отдельно не описаны.
- При обучении использовалась максимальная длина 512 токенов; в сервисе текст перед подачей в модель предполагается обрезать до этого значения, поэтому у длинных отзывов модель увидит только начало.

## Выходные данные

- Вероятности трех классов: `negative`, `neutral`, `positive` (softmax на выходе модели).
- В API передаются два значения: `sentiment` — класс с максимальной вероятностью и `confidence` — вероятность этого класса в диапазоне от 0 до 1.
- Модель не возвращает объяснение решения, фрагменты текста или причины выбора класса.

## Метрики качества

Метрики взяты из карточки модели. Авторы измеряли их на объединенном тестовом наборе из 12626 примеров.

| class | Precision | Recall | F1-score | AUC-ROC | support |
|---|---|---|---|---|---|
| neutral | 0.70 | 0.74 | 0.72 | 0.85 | 5196 |
| positive | 0.84 | 0.83 | 0.83 | 0.95 | 3831 |
| negative | 0.74 | 0.69 | 0.71 | 0.91 | 3599 |
| macro avg | 0.76 | 0.75 | 0.75 | 0.90 | 12626 |
| weighted avg | 0.75 | 0.75 | 0.75 | 0.90 | 12626 |

Метрики получены авторами модели на их тестовой выборке. На отзывах нашего сервиса модель не оценивалась, поэтому эти значения нельзя считать гарантией качества в проекте.

## Ограничения

Ограничения, указанные авторами модели:

- модель предназначена для коротких русскоязычных текстов;
- при обучении использовалась максимальная длина 512 токенов, более длинные тексты обрезаются;
- обучающие данные — объединение пяти наборов из разных доменов (социальные сети, новости, отзывы) и метрики усреднены по этому объединению;
- F1 классов `negative` (0.71) и `neutral` (0.72) заметно ниже, чем у `positive` (0.83); precision у `neutral` самая низкая (0.70).

Потенциальные ограничения для нашего проекта:

- отзывы длиной до 2000 символов могут не помещаться в 512 токенов, и решение принимается по усеченному тексту;
- наш сервис принимает отзывы о разных товарах и услугах а в обучающих данных отзывы относятся к одной категории и к социальным медиа — качество на других категориях не проверено;
- калибровка `confidence` авторами не описана, поэтому порог 0.6 из US-02 требует проверки на наших данных;
- ирония, сарказм, отрицания, смешанные языки и опечатки могут приводить к ошибкам - доступной информации недостаточно для оценки качества на таких текстах.

## Не рекомендуется использовать

- для медицинских, юридических или финансовых решений;
- для автоматического удаления отзывов или отказа пользователю без проверки человеком;
- для оценки личности автора отзыва или его эмоционального состояния;
- для текстов на других языках и для длинных документов (статьи, транскрипты звонков);
- для анализа тональности не отзыва, а например описания товара или инструкции.
