# API

API предоставляет доступ к функциям ИИ-сервиса «Анализатор отзывов».

## Основные операции

- `POST /analysis` — выполнить анализ тональности отзыва;
- `GET /analysis/{id}` — получить сохраненный результат анализа;
- `GET /models` — получить список доступных моделей.

Каждая операция содержит описание параметров:

- `POST /analysis` — header-параметр `X-Request-ID` (трассировка запроса);
- `GET /analysis/{id}` — path-параметр `id`;
- `GET /models` — query-параметры `activeOnly` и `limit`.

## Спецификация

Полное описание API находится в файле `openapi.yaml` (OpenAPI 3.0.3).

Спецификация описывает:

- тело запроса (`requestBody`) для `POST /analysis`;
- path-, query- и header-параметры;
- успешные ответы со схемами `AnalysisResult` и `ModelInfo`;
- коды ошибок `400`, `404`, `500`, `503` со схемой `Error`;
- переиспользуемые схемы в `components/schemas`, на которые ссылается `$ref`.
